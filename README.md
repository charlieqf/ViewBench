# ViewBench 播放验证工作台

Windows / macOS 桌面客户端方案：同一视频链接，默认 4 路独立浏览器通过不同代理出口并发播放，各路默认静音。首版计划支持抖音和通用 HTML5 视频页，外置配置保留约 10 个实播筛选的节点供常用和备用。

当前仓库包含需求材料、离线互动原型和实施方案，尚无客户端实现。

- [实施方案](播放验证工作台_实施方案.md)：本次开发范围、技术架构、IP 池配置、平台适配和验证步骤。
- [客户需求说明书](播放验证工作台_需求说明书.md)
- [客户 PRD](播放验证工作台_PRD.md)
- [客户互动原型](播放验证工作台_互动原型.html)：下载后在浏览器打开，内容为离线模拟。
- [代理配置示例](proxies.example.txt)：全部为虚构数据，真实配置使用外置的 `proxies.private.txt`。

客户原始资料保持原样；双平台、必须并发及本次精简范围以实施方案为准。
